# Movies
Aplicativo de estudo utilizando a linguagem swift, que tem como objetivo consumir a API theMovieDB e aprimorar meus conhecimentos com o viewCode.

# Solucao
Nesse projeto foi utilizado a arquitetura MVVM-C pensando justamente na separacao da logica da vizualizacao e facilitacao na criacao dos testes unitarios. Foi utilizado o modelo de viewCode para criacao das telas, o projeto atualmente nao conta com nenhuma dependencia, mas pode ser pensado em adicionar futuramente.
Alem do mais, o projeto utiliza de Design Patterns, boas praticas de programacao, codigo limpo, conceitos SOLID e gereciamento de memoria ARC.
Foi implementado a camada de rede utilizando URLSession.

# Começando
Para rodar o projeto, voce simplesmente abre o projeto e aguarde baixar os pacotes.
O app solicita uma API Key do TMDB website para rodar, adicione sua chave API Key na variavel "Authorization" que esta dentro da pasta Utils/Constants/AppConstant como mostra no print a seguir.
